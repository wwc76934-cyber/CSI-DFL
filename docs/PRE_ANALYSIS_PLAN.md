## v2 修订记录（吸收独立评审意见后的严谨性升级）

在 v1（提交 `a12a47b`）完成首次开发期运行后，依据独立审稿意见发现并锁定以下方法论修复（不新增因子、不做超参数调优，纯粹修补审计漏洞与补齐关键对照组）：

1. **移除行业未来回填 + 如实审计季报非首次披露属性**：
   - 行业分类严格按 `start_date <= signal_date` 对齐，生效前保留 `"Other"`，不再用未来最早记录回填；
   - `ak.stock_yjbb_em` 的“最新公告日期”被证实几乎全部为后期重述刷新日（触发法定截止日回退比例 `99.998%`），因此不再硬编码 `pit_quarterly_passed = True`，改为如实输出回退比例，并强制增加**剔除 3 个东财季报因子的 7 因子纯 PIT 消融对照**（仅用经核实按公告日更新的 BaoStock `peTTM`/`pbMRQ` 与量价因子）。
2. **拆分开盘可交易性与收盘有效性 + 对齐真实持有区间**：
   - `backtest.py` 开盘下单只读取开盘前可知的 `open_tradable`（`raw_open > 0`, `hfq_open > 0`, `tradestatus == 1`），收盘估值与信号计算使用 `close_ok`；
   - 训练与评价持有区间统一对齐至真实相邻两次调仓开盘日 `[entry_date, next_entry_date]`（解决长假前后与固定 `+5` 交易日错位问题）。
3. **补齐完整归因对照组与配对统计检验**：
   - 同引擎运行 **`B0_FloatMV_Anchor`**（纯流通市值锚）、**`S0_EqualWeight`**（10 因子等权）、**`S0_LowTurn_Band`**（10 因子等权 + 简单无参数权重平滑 $\alpha = 0.65$，检验简单低换手规则能否复制 DFL）、**`S1_RollingRidge`** 与 **`S2_WhiteboxDFL`**；
   - 强制输出 **`S2 - S1`、`S2 - S0`、`S2 - S0_LowTurn_Band`、`Strategy - B0_FloatMV_Anchor`** 的配对日度净收益 Newey-West $t$ 检验与区块自助法（Circular Block Bootstrap, `block=10`, `2000` 次）95% 置信区间；同时输出 `N=3`（仓内）与 `N=10`（计入前序 `dfl-csi-alpha` 探索试验）两档 DSR 敏感性。
4. **对齐 DFL 训练换手目标与真实组合漂移换手**：
   - 将训练损失中的代理换手 $\|\Delta w_t - \Delta w_{t-1}\|_1$ 升级为包含锚变动与股价漂移的**真实全组合漂移换手** $\|w_t - w_{t-1}^{\text{drifted}}\|_1$，并逐周对账训练换手、目标换手与实际成交换手；额外执行 `5` 个随机种子（`42..46`）稳定性检验。
5. **更真实的 A 股成本基准、容量压力与实际成交暴露审计**：
   - 将 **单边 `20 bp`** 与 **A 股分段真实成本**（买单佣金 `2.5 bp` + 开盘滑点 `7.5 bp` = `10 bp`；卖单印花税 `2023-08-28` 前 `10 bp` / 后 `5 bp` + 佣金 `2.5 bp` + 滑点 `7.5 bp`）作为主评价基准，并同步保留 `0 bp` 毛收益与 `10 bp` 机构乐观参考；
   - 增加 `100 万 / 1,000 万 / 1 亿` 三档规模容量测试（按前一日成交额 `5%` 设置严格无未来函数的参与率上限），并按调仓日实际成交持仓审计真实行业、Beta、市值暴露与现金占比。

## 1. 研究假设

- **H1（10 因子在同引擎自建锚之上的选股能力）**：经申万一级行业 + 对数流通市值双中性化后的 10 个经典因子，在剔除 `FloatMV` 锚相对 `H00905` 的基准差异后，仍能产生正的选股毛超额（并检验在剔除 3 个非首次披露季报因子的 7 因子纯 PIT 口径下是否稳健）。
- **H2（白盒 DFL 相对两阶段 Ridge 的显著优势）**：端到端优化扣费净 IR 的 `S2_WhiteboxDFL` 在配对日度净收益上显著跑赢两阶段 `S1_RollingRidge`（检验 `S2 - S1` 配对 Newey-West $t$ 与 95% 置信区间）。
- **H3（白盒 DFL 相对等权与简单低换手规则的增量检验）**：严格检验 `S2_WhiteboxDFL` 相对 `S0_EqualWeight` 与 `S0_LowTurn_Band` 的配对净增量是否统计显著；若增量微弱或不显著，如实报告“DFL 主要收益来自低换手摩擦节省，尚未显著超越简单等权/低换手基线”。

## 4. 锁定的风控、成本与统计协议

- **可行域约束**：仅做多满仓、个股上限 `max(4.0%, anchor)`、个股主动偏离 `±1.5%`、申万一级行业中性、Beta 中性、对数市值中性（训练 12 步 / 推理 30 步 Dykstra 投影）。
- **四档成本口径**：`0 bp`（毛收益归因）、`10 bp`（乐观机构参考）、`20 bp`（保守基准情形）、`ashare_realistic`（A 股分段印花税 + 佣金 + 开盘滑点）。
- **统计与审计必选项**：单策略 vs `H00905` 与 `B0_FloatMV_Anchor` 检验、关键模型两两配对 Newey-West $t$ 与区块自助法 95% CI、DSR（`N=3` & `N=10`）、CSCV PBO、实际成交持仓风险暴露、训练/目标/实际三口径换手对账、5 种子稳健性与三档资金容量压力测试。
